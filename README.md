# TJ Rodriguez - Project Zed Marvel Rivals Stats Tracker

A personal app that serves as a tool to help players of the video game, Marvel Rivals track their match statistics in order to improve their playstyle. This is also Project Zed for the WRIT 40363 Fall 2026 class.

**Live site:** https://tjrod28.github.io/zed/

## Built with

- Semantic HTML
- CSS with design tokens and padding tokens
- JavaScript functions
- Git and GitHub Pages
- Assisted in development with Claude AI

## Notes

It is very important to note that the main theme of Project Zed was for us as students in the Fall WRIT 40363 class to create an app of our choosing that utilizes AI. We had a choice in whatever AI we wanted to use with my natural preferance being Claude. The ultimate goal was for us to build an app ALONGSIDE AI, who helped us with complex functions and loops, while remaining faithful to the structure and practices we learned in class. This project serves as a unique combination of all the previous projects I have created for this class this semester. This statement is evident to anyone who views my previous work before utilizing this custom stats tracker. I pulled techniques and formats from the other three projects to create a very professional yet user-friendly app companion. The major bulk of the code is repurposed and updated code borrowed directly from my very own Project 2: Local Favorites Tracker. One entirely new feature for this application is the fact there is an option to export all data on the app into a CSV File to be shared with whoever the user wishes and to always keep on their device if their local storage ever becomes corrupted or deleted.

VERY IMPORTANT INFO: When opening the CSV in Excel: if the Date column or any other column shows #####, the column is just too narrow. Double-click the line between the A and B column letters to widen it. Or slide the cursor to widen the column. Google Sheets shows dates normally.
